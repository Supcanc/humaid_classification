# About this project

This project can be used by the emergency services to classify messages from people about different accidents and decide which demands immediate attention.

# Prerequisites

- Git
- Docker
- Docker-compose

# Installation guide

1. Clone this project to your machine by using this command in your terminal:

```git clone https://github.com/Supcanc/humaid_classification```

2. Go to the project directory with this command:

```cd humaid_classification```

3. Use this command in your terminal to launch docker-compose and start the app:

```docker compose up -d```

4. After docker compose start you can use the app in your browser by this link:

```localhost:8501```

5. You can close the app by typing this command in your terminal:

```docker compose down```
